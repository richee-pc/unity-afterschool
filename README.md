## 📁 파일 설명

| 파일 | 뭐 하는 파일인가 |
|---|---|
| **`index.html`** | **실제로 배포되는 페이지. 이것 하나면 끝입니다.** |
| `board.html` | 원본 조각 (Claude Artifact 용). 배포에는 안 쓰입니다 |
| `build.py` | `board.html` → `index.html` 로 감싸 주는 스크립트 |
| `streamlit_app.py` | Streamlit 으로 띄우고 싶을 때만 사용 (선택) |
| `requirements.txt` | Streamlit 용 패키지 목록 (선택) |

`index.html` **하나만 있으면 어디서든 열립니다.** 인터넷이 끊겨도 파일을 더블클릭하면 열려요.

## 🚀 GitHub Pages 켜는 법 (5분)

1. 이 저장소 페이지에서 상단 **Settings**
2. 왼쪽 메뉴 맨 아래쯤 **Pages**
3. **Source** 를 `Deploy from a branch` 로
4. **Branch** 를 `main` / `/ (root)` 로 선택하고 **Save**
5. 1~2분 뒤 새로고침하면 맨 위에 주소가 뜹니다

> ⚠️ 무료 계정은 **공개(Public) 저장소**에서만 Pages 가 동작합니다.

---

## ✏️ 내용 수정하는 법

가장 쉬운 방법 — **깃허브 웹에서 바로 고치기**

1. 저장소에서 `index.html` 클릭
2. 오른쪽 위 **연필(✏️) 아이콘**
3. 고치고 맨 아래 **Commit changes**
4. 1~2분 뒤 학생 페이지에 자동 반영

수정할 내용이 많으면 `board.html` 을 고치고 아래를 실행해도 됩니다.

```bash
python build.py
```

## 🐍 Streamlit 으로 띄우고 싶다면 (선택)

`streamlit_app.py` 가 들어 있습니다. 다만 **GitHub Pages 를 권합니다** —
Streamlit 은 페이지를 iframe 안에 넣기 때문에 차시별 링크(`#stage7`)가 동작하지 않고,
무료 플랜은 일정 기간 접속이 없으면 앱이 잠들어 학생이 기다려야 합니다.

그래도 쓰시려면 [share.streamlit.io](https://share.streamlit.io) 에서 이 저장소를 연결하고
Main file 을 `streamlit_app.py` 로 지정하면 됩니다.
