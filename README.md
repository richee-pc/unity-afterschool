## 🤖 생성형 AI 활용 방침

학생이 AI를 **"대신 만들어 주는 기계"가 아니라 "옆자리 선배"** 로 쓰도록 설계했습니다.

쓰는 도구는 **ChatGPT**(`chatgpt.com`) 와 **제미나이**(`gemini.google.com`) 입니다.
제미나이는 학교 구글 계정으로 바로 들어가집니다. **팀마다 하나를 정해 3주 내내 같은 것**을 쓰게 안내했습니다 — 대화가 이어져야 "아까 그 코드" 가 통하기 때문입니다.

5차시에 **「ChatGPT · 제미나이 — 이렇게 씁니다」** 표를 두어 접속·새 대화·붙여넣기·
코드 복사(드래그 금지)·이어 묻기까지 안내합니다.

| 원칙 | 페이지에 반영된 곳 |
|---|---|
| 한 번에 기능 하나만 요청 | P3 프롬프트, 6차시 개념 카드 |
| 이해 못 한 코드는 쓰지 않는다 | P2 프롬프트, 6차시 도전 3 |
| 붙이기 전에 백업 | 6차시 미션 4·7 |
| 개인정보를 넣지 않는다 | 5·6차시 ⚠️ 주의 카드 |
| 발표에서 AI 활용을 밝힌다 | 7차시 발표 대본 ④, AI 활용 기록표 |

**AI를 쓸 수 없는 환경이어도 수업은 그대로 됩니다.** 기능 레시피 10종만으로
레벨 3까지 도달할 수 있고, 그렇게 안내 문구도 넣어 두었습니다.

## 📁 파일 설명

| 파일 | 뭐 하는 파일인가 |
|---|---|
| **`index.html`** | **실제로 배포되는 페이지. 이것 하나면 끝입니다.** |
| **`teams/index.html`** | 작품 전시관 (체험 창 + 관람 스탬프) |
| `teams/team1.html` … | 팀별 작품 파일 |
| `board.html` | 원본 조각 (Claude Artifact 용). 배포에는 안 쓰입니다 |
| `build.py` | `board.html` → `index.html` 로 감싸 주는 스크립트 |
| `archive-unity.html` | 유니티 시절 미션보드 (보관용) |
| `streamlit_app.py` | Streamlit 으로 띄우고 싶을 때만 사용 (선택) |

`index.html` **하나만 있으면 어디서든 열립니다.** 인터넷이 끊겨도 파일을 더블클릭하면 열려요.

## 🏆 작품 전시관에 올리는 법

1. 팀에게 받은 파일을 `team2.html` … `team6.html` 로 이름을 바꿔 `teams/` 폴더에 올립니다.
2. `teams/index.html` 맨 아래 `TEAMS` 목록에서 그 팀의 `ready` 를 `true` 로 바꾸고
   앱 이름·소개·팀원을 채웁니다.
3. 저장하고 올리면 1~2분 뒤 자동으로 전시됩니다.

전시관에서는 카드를 누르면 **그 자리에서 앱을 체험**할 수 있고,
10초 이상 보면 **관람 스탬프**가 찍힙니다 (7차시 도전 3과 연결).

## ✏️ 내용 수정하는 법

가장 쉬운 방법 — **깃허브 웹에서 바로 고치기**

1. 저장소에서 `index.html` 클릭
2. 오른쪽 위 **연필(✏️) 아이콘**
3. 고치고 맨 아래 **Commit changes**
4. 1~2분 뒤 학생 페이지에 자동 반영

수정할 내용이 많으면 `board.html` 을 고치고 아래를 실행해도 됩니다.

```bash
python build.py
```

## 🚀 GitHub Pages 설정 (이미 켜져 있습니다)

1. 저장소 **Settings** → 왼쪽 **Pages**
2. **Source** 를 `Deploy from a branch`
3. **Branch** 를 `main` / `/ (root)` → **Save**

> ⚠️ 무료 계정은 **공개(Public) 저장소**에서만 Pages 가 동작합니다.
